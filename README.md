# Satellite Imagery Analysis

Source for the **Satellite Imagery Analysis** module of the [Workshop 2026](https://spatialturn.github.io/workshop2026.html) materials, part of [Enabling the Geospatial Turn in the Social Sciences](https://spatialturn.github.io/).
Published at <https://spatialturn.github.io/Workshop2026-Session3A/>.

Analysis of Sentinel-2 satellite imagery in QGIS: vegetation mapping with NDVI and flood mapping with false color composites and NDWI.

The lesson is built with [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/).
It is kept as it was taught at the workshop (Day 1, Session A QGIS track, part 3).

| Episode file | Title |
|---|---|
| `episodes/ndvi-analysis.md` | Exercises: NDVI Analysis with Sentinel-2 Imagery |
| `episodes/flood-analysis.md` | Exercises: Flood Analysis with False Color Composites and NDWI |
